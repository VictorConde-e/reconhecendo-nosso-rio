    Carregar a tabela de peixes

    O navegador não deixou ler especies.json sozinho. Isso é normal quando a página é aberta com dois cliques (file://).

    Escolha o arquivo web/especies.json abaixo. Ele fica salvo neste navegador para as próximas vezes.

    Outra opção: na pasta web, rode python3 -m http.server 8000 e abra http://localhost:8000. Assim ele lê o arquivo direto, inclusive depois de editado.
